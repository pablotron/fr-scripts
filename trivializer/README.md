# fr-trivializer

Fetch [FedRAMP trivia][]  questions and answers, then print them to
standard output as a CSV file.

Scripts:

- [fr-trivializer.py](./fr-trivializer.py): Extract questions and
  answers and save them to standard output as a CSV file.
- [fr-min.py](./fr-min.py): Minified version of `fr-trivializer.py`.
- [fr-min.py](./fr-min.py): Create obfuscated version of `fr-min.py`.

[fedramp trivia]: https://www.fedramp.gov/trivia/
  "FedRAMP trivia"
